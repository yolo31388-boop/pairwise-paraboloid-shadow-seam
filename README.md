# pairwise-paraboloid-shadow-seam

探照灯扫过墙面时，背面突然亮起一道竖线，双抛物面阴影图在极点处的接缝没有做环绕，采样落在图外；近平面裁剪把灯具自身几何切掉，灯座在地面投出一圈黑洞；抛物面参数按 90 度半角假设，广角灯的实际半角更大，边缘物体漏出阴影；两张抛物面图共用一张图集，采样 uv 没有加各半的偏移，正面阴影投到了背面；深度比较用了线性深度，抛物面空间的非线性让远处偏差爆掉；灯具旋转后抛物线基向量没重建，阴影方向跟着世界轴；极点在纹理 v=0 与 v=1 两侧采样，双线性插值跨接缝取到对侧；阴影图分辨率固定 1024，聚光角度收窄后边缘全是块；物体在光源背后时深度为负，裁剪空间把负深度钳成零，背面出现假阴影；多盏聚光灯共享一次渲染目标，清屏只在第一盏前做，后面的灯叠加了前一张图。render/paraboloid_shadow_seam.py 是核心，tests/test_paraboloid_shadow_seam.py 15个红。要修的是：接缝环绕采样；近平面按灯半径；按实际半角参数化；图集偏移；存抛物面距离；随灯重建基；接缝独立处理；按角分辨率；负深度单独标记；每盏清屏。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
